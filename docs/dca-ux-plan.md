# Spendiary: แผนปรับ UX ของ DCA (ผู้ใช้ใหม่เข้าใจได้)

> เริ่ม 18 ต.ค. 2026 · main = **1.30.0** (`b85b71c`)
> ระบบเดิมทำงานถูกแล้ว แผนนี้แก้ที่ "ภาพในหัว" ของผู้ใช้ใหม่: DCA คืออะไร บันทึกที่ไหน เงินไปไหน

---

## 0. หลักที่ใช้

| หลัก | แปลว่า |
|---|---|
| **หนึ่งบ้าน หลายประตู** | หน้า DCA (Invest) เป็นเจ้าของแผน · Today stack (Spend) เป็นทางลัด มีปุ่มหลักชุดเดียวกัน และบอกว่ามาจากไหน |
| **แอปไม่ได้ซื้อให้** | ทุกคำต้องบอกว่าเป็นการ "บันทึก" ไม่ใช่ "สั่งซื้อ" |
| **ตอบแค่สองคำถาม** | จ่ายไปเท่าไหร่ได้อะไรมา · ตอนนี้มีรวมเท่าไหร่ ที่เหลือพับไว้ |
| **แดง = เสียเงินจริง** | บิล/หนี้ที่เลยกำหนดเท่านั้น DCA ที่พลาดเป็นแค่การเตือน |
| **ตัวเลขเดียวกัน มาจากที่เดียวกัน** | badge / แบนเนอร์ / หัวการ์ด ต้องนับตรงกัน |

## 1. รายการงาน (เรียงตามลำดับที่ทำ)

### B. Preview ในฟอร์มบันทึกการซื้อ (`ConfirmDcaBuyForm.tsx`)
| # | งาน | สถานะ |
|---|---|---|
| B1 | Preview เหลือ 2 บรรทัด: **This buy** (฿ → ที่ได้มา) และ **Your total** · ใช้โครงเดียวกันทุกสินทรัพย์ (BTC, หุ้น, กองทุน, ทอง) | ✅ |
| B2 | ราคาต่อหน่วย + avg cost ย้ายไป **Details** ที่พับไว้ เป็นบาท | ✅ |
| B3 | เตือนเมื่อราคาที่คำนวณได้ต่างจากราคาตลาดเกิน ±20% (แทนตัวช่วยจับพิมพ์ผิดที่ถูกพับไป) | ✅ |
| B4 | ลบป้าย "Purchase Preview (Before → After)", "Digits only", "Max 4 decimals" | ✅ |

### A. คำ (ผู้ใช้ใหม่)
| # | งาน | สถานะ |
|---|---|---|
| A1 | "Confirm Buy" → **"Log buy"** / "I bought it" ทุกที่ + บรรทัด *"Spendiary doesn't trade for you — log it after you buy at your broker."* | ✅ |
| A2 | หัวฟอร์ม `Log buy: Bitcoin` · ปุ่ม `Log ฿300 buy` | ✅ |

### C. หนึ่งบ้าน หลายประตู
| # | งาน | สถานะ |
|---|---|---|
| C1 | เพิ่ม **Skip** (มี Undo) ใน Today stack | ✅ |
| C2 | ป้าย `Invest · DCA` บนกลุ่ม DCA ใน Today stack | ✅ |
| C3 | แบนเนอร์บน Invest Home: DCA พาไป `/dca` อยู่โหมดเดิม · บิล/หนี้ยังพาไป Spend Home | ✅ |

### E. สีและตัวเลข
| # | งาน | สถานะ |
|---|---|---|
| E1 | DCA ที่พลาดไม่ใช้สีแดง · คำว่า "late" / "Overdue" → **"Missed 15 Oct"** · "Confirmed" → "Logged" | ✅ |
| E2 | ตัวนับ "N due or late" → "N due now" นับจากวันจริง (เลยกำหนด/ถึงวันนี้) ไม่ใช่จากสี | ✅ |
| E3 | badge ทุกที่ที่พูดเรื่องเดียวกันนับจากที่เดียวกัน: แถว DCA บน Invest Home = badge แท็บ DCA (`shouldConfirmBuy`) · badge ฝั่ง Spend ยังนับตามหน้าของตัวเอง (Home = recurring, Accounts = บิลบัตร, Loans = หนี้) | ✅ |

### D. Feedback หลังบันทึก
| # | งาน | สถานะ |
|---|---|---|
| D1 | Popup หลังบันทึก: `KBank Savings → Bitcoin` + ปุ่ม **Undo** | ✅ |

### F. ค่อยๆ เปิดเผย
| # | งาน | สถานะ |
|---|---|---|
| F1 | Coach mark ครั้งเดียว ตอน DCA โผล่ใน Today stack ครั้งแรก | ⬜ |
