## 0. ทำไมต้องทำใหม่

หน้าแรกตอนนี้ (`AppContent` ใน `src/App.tsx` ตอนยังไม่ล็อกอิน) เป็นหน้าขายของแบบ SaaS template ซึ่งขัดกับ `PRODUCT.md` (*"Private by default — not demonstrative"*) และมีข้อความที่ไม่จริง

| จุดที่ฟ้องว่าเป็น AI slop | ทำไม |
|---|---|
| Pill sparkle "The intelligent personal wealth cockpit" | pattern ที่เจอบ่อยสุดของ landing ที่ AI gen คำว่า intelligent / cockpit ไม่ได้บอกอะไร |
| หัวข้อ "Spend smarter. / Now live wealthier." บรรทัดสองสี brand | สูตร "X. Y-er." และภาษาแปลก |
| Gradient พาสเทล ส้มพีชไปลาเวนเดอร์ (`.fastwork-canvas`) | ค่า default ของ "modern SaaS" และลอกโทนมาจาก Fastwork |
| การ์ดฟีเจอร์ 3 ใบ (ไอคอนในกรอบสีอ่อน + หัวข้อ + 2 บรรทัด) | template สลับใส่แอปไหนก็ได้ |
| Pill "Smart Wealth · 2026 Edition" + จุดเขียวกะพริบ | ไม่มีอะไร live และไม่มี "edition" |
| Buzzword: intelligent, reinventing, smart, bank-grade, 100% | ยิ่งเคลมเยอะ ยิ่งดูไม่จริง |
| ไม่มีภาพตัวแอปจริง | หน้านี้ขายแอปไหนก็ได้ ไม่ได้ขาย Spendiary |

**ข้อความที่ไม่จริง (ต้องลบ):**

| ข้อความ | ความจริง |
|---|---|
| "Your financial records stay **local on your device**" | ข้อมูลอยู่ใน Supabase (`user_data.payload`) |
| "**100% Client Privacy**" / "**Bank-grade** Privacy" | เป็น Supabase + RLS ธรรมดา ไม่มีการเข้ารหัสฝั่ง client |
| "automated rebalancing & smart buy notifications" | ต้องเช็กว่าแอปทำได้จริงไหม ถ้าไม่ได้ให้ลบ |

## 1. เป้าหมายของหน้า

| กลุ่ม | ต้องการอะไร | หน้าต้องทำอะไร |
|---|---|---|

## 2. หลักการ (จาก `PRODUCT.md`)

- **Premium · Precise · Calm**: อ้างอิงแนว Apple, Linear และ Copilot Money (+ ไอเดียจาก paypers.ai ในหัวข้อ 11.1)
- **โชว์ของจริงแทนการโม้**: ภาพหน้าจอจริงจากโหมด Demo
- **ทุกประโยคต้องจริง**: ไม่มีคำเคลมที่ตรวจสอบไม่ได้
- **ใช้สีเมื่อมีความหมายเท่านั้น**: ไม่มี gradient ตกแต่ง
- **เอาแนวทางมาใช้ ไม่ลอก**: ใช้เว็บอ้างอิงเป็นแรงบันดาลใจ ไม่ลอกจนเหมือน

## 7. ภาพหน้าจอจริง

- **ที่มา:** ถ่ายจากโหมด Demo ด้วย Puppeteer ตัวเดียวกับที่ `promo/capture.mjs` ใช้ ไม่ต้องลง Playwright เพิ่ม (ไม่มีข้อมูลจริงของใคร)
- **จำนวน:** 3 ภาพ คือ Spend Overview บนจอคอม, Spend บนมือถือ และ Portfolio บนมือถือ
- **ทำซ้ำได้:** สคริปต์อยู่ที่ `promo/landing-shots.mjs` เปิด `npm run dev` ไว้ แล้วรัน `npm run landing` ในโฟลเดอร์ `promo/` ทุกครั้งที่ UI เปลี่ยน สคริปต์จะซ่อนแถบ Test mode และกดปิด tip ที่ขึ้นครั้งเดียว (Got it) ก่อนถ่าย
- **ไฟล์:** WebP หรือ JPEG ภาพละไม่เกินประมาณ 150KB, ใส่ `width`/`height` กัน layout กระโดด, ภาพที่อยู่ใต้ขอบจอใช้ `loading="lazy"`
- **ที่เก็บ:** `public/landing/`

## 9. หน้า Privacy (`/privacy`)

หน้าข้อความเรียบๆ ภาษาไทย เปิดได้โดยไม่ต้องล็อกอิน (ตอนนี้ `AppContent` ส่งทุก path ไปหน้าแรกถ้ายังไม่ล็อกอิน ต้องยกเว้น `/privacy`)

1. เก็บข้อมูลอะไรบ้าง
2. เก็บที่ไหน: Supabase (เช็ก region ใน dashboard → Project Settings)
3. ใครเข้าถึงได้: ตัวคุณ และ**ผู้ดูแลระบบ** (ต้องบอกตรงๆ)
4. บริการภายนอก: Google (ล็อกอิน), Vercel (โฮสต์เว็บ), Edge Function `smart-responder` ที่ดึงราคาหุ้น (ส่งไปแค่ชื่อหุ้น) และแหล่งอัตรา USD/THB
5. วิธีลบข้อมูล (Clear all data) และวิธีขอลบบัญชี
6. ติดต่อ: "ผู้ดูแลระบบ (คนที่ส่งคำเชิญให้คุณ)" ไม่ใส่อีเมลส่วนตัวบนเว็บ

> ไม่ใช่เอกสาร PDPA ฉบับเต็ม ถ้าจะเปิดสาธารณะควรปรึกษาผู้รู้

## 10. นอกขอบเขต design รอบนี้ (ต้องทำก่อนชวนคน)

| งาน | ทำที่ไหน | หมายเหตุ |
|---|---|---|
| **ระบบเชิญ** | Supabase dashboard | ปิด *Allow new users to sign up* แล้วเพิ่มคนผ่าน Authentication → Users → Add user → Create new user (auto-confirm) **ต้องลองกับเพื่อน 1 คนก่อน** ว่า Google login ผูกเข้าบัญชีที่สร้างแบบนี้ได้ |
| **SMTP** | Supabase → Emails → SMTP | ย้ายจาก Gmail ส่วนตัวไป Resend / Brevo + โดเมนตัวเอง |
| **Google OAuth** | Google Cloud Console → OAuth consent screen | ถ้ายังเป็น *Testing* ให้กด *Publish app* (scope email/profile ไม่ต้องรอ verify) |
| **ตัวแอปเป็นภาษาอังกฤษ** | ทั้งแอป | หน้าแรกไทย แต่ข้างในอังกฤษ ควรแยกเป็นอีกรอบ |
| **`PRODUCT.md`** | repo | ยังเขียนว่า "Single user: Praween" ต้องอัปเดตกลุ่มผู้ใช้ |
