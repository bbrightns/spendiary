#### What's Working
1. **Spotlight-Style Command Palette (`⌘K` / `Ctrl+K`)**:
   - ค้นหาและกระโดดไปยังหน้าใดก็ได้ทันที
   - ค้นหาสินทรัพย์ที่มีอยู่ในพอร์ตสด ๆ พร้อมแสดงมูลค่าแบบเรียลไทม์
   - ทางลัดสร้างรายการด่วน (`Record New Holding`, `Record Debt`, `Add DCA Plan`, `Add Cash Account`)
   - สลับธีม Dark / Light และส่งออกไฟล์สำรองข้อมูล JSON ได้ในเสี้ยววินาที
2. **Actionable Toast with Instant Undo**:
   - เมื่อบันทึกจ่ายหนี้สิน มีปุ่ม `เลิกทำ (Undo)` ให้กดย้อนสถานะได้ทันที
3. **Refined Page Loading Skeleton**:
   - การสลับหน้าระหว่างพอร์ต, DCA และหนี้สิน มี Shimmering Skeleton Loader ป้องกันการกระตุกของสายตา
